# AGENTS.md — A-闪卡 AI 流程指令

> 本文件随 `~/projects/opensource/ai-tools` 仓库管理（`skills/flashcard/AGENTS.md`），改动请提交并跑 `sync.sh`。
> 任何 AI 处理 `A-闪卡` 目录，按本文件操作。不需要猜，不需要重新调研。
> 理论详见 `~/obsidian-notes/work-notes/A-闪卡/记忆卡片方法论.md`，插件语法详见同目录的 `SR插件制卡最佳实践.md`。

## 制卡流程

```
1. 读目标知识点所属的源笔记          ← 确认出处，卡背面必挂出处链接
2. 判断值不值得做（见"选材"）        ← 不值得就停
3. 按统一格式模板制卡                ← 见下方"格式模板"，直接抄
4. 英语卡：生成发音 + 搜图           ← 见"发音卡"一节
5. 自检                              ← 6 条，任一不过=改卡
```

## 选材（先判断，不做就不做）

**只做"见过但不会用"的——回报率最高。**

- 完全陌生 → 先理解，别急着做卡（不理解=死记，SRS 救不了）
- 见过但不会用 → ✅ 做
- 完全掌握 → ❌ 不做

**广泛阅读选材**：选能理解 90-95% 内容的分级读物/简化新闻/原版小说。遇到生词先根据上下文猜，再查证，再制卡。语境输入是最佳来源——为乐趣和整体意义而读，不刻意分析每个词。

## 做几张

- 低频/一次性 → 1~2 张
- 高频核心/易错 → 3~6 张
- 单点 ≤ 6 张（经验值）

## 4 个通用维度

| 维度 | 问 | 英语落地 | 数学落地 | 编程落地 |
|---|---|---|---|---|
| 识别 | 认得吗 | 英→中 | 认公式 | 认 API |
| 产出 | 会用吗 | 中→英 | 能推导 | 能写出来 |
| 结构 | 怎么连 | 搭配 / 介词 | 适用条件 | 参数 / 依赖 |
| 边界 | 何时用、何时不用 | 语域 / 贬褒义 | 反例 | 陷阱 |

## 格式模板（统一两层标题 + 正文正面，直接抄）

```
---
created: <日期>
tags:
source: <来源>
---
#flashcards

# 一、<分组名>

## 1.x <小节名>

#flashcards/<学科>/<子主题>

正面文字（正文行，不是标题）
?
<答案>
⚠️ 易错：<...>
🧠 记法：<...>
![[T-附件/audio/<word>.mp3]]
出处：<[[源笔记]]>
```

**正面为什么不是标题**（源码核实）：heading 会被 `getQuestionContext` 收进面包屑，而 `?` 之前的内容又渲染进卡片正文 → 同一句话显示两遍（卡上方一遍、正面一遍）。改成正文行只显示一遍，且**正面文字不再进面包屑**，泄底面自然收窄。

**关键格式规则**：
- `#flashcards/<学科>/<子主题>` 必须**独立成行，前后留空行**（源码核实：标签行才被识别为内容级标签，对其后所有卡生效）
- **正面正文行下一行直接写 `?`，中间不能有空行**（源码核实：本库 `multilineCardEndMarker=''`，任何空行都会清空 `cardText`；空行后再写 `?` 时 `cardText.length>1` 不成立 → 卡型设不上 → **该卡静默不生成**）
- `?` 独占一行，前后不能有其它内容
- 卡间用空行分隔（空行是卡片结束信号）
- **卡片正面不用 `###`**：`#`/`##` 只作分组与小节（它们进面包屑，所以措辞必须中性、不含答案）；正面写正文
- **Cloze 卡没有正反切分**：除 `==挖空==` 外**所有文本两面都渲染**（源码：`QuestionTypeCloze.expand` 走 clozecraft 的 front/back，共享非挖空文本）。所以——
  - ❌ 别把译文/答案解释留在 Cloze 行上（`==Artificial== General Intelligence (AGI) —— 通用人工智能` 的「通用人工智能」会直接显示在正面）
  - ❌ 别给 Cloze 卡挂发音链接或 IPA（Cloze 无正反切分，两面都出，等于正面报答案）；发音归独立的发音卡
  - Cloze 卡内容与 `出处` 行**紧贴无空行**，否则空行截断卡片文本，`出处` 变孤儿行（两面都不显示）
- `<!--SR:-->` 不要手写（插件复习后自动追加）

## 卡型选择

| 测什么 | 卡型 | 语法 |
|---|---|---|
| 语境识别 | Cloze | `==挖空==` |
| 产出/结构/边界 | 多行 basic | `Q` 换行 `?` 换行 `A` |
| 发音（感知通道） | 多行 basic | 正面图片→背面 IPA + 发音链接 + 音频 |
| 双向产出 | 多行反转 | `Q` 换行 `??` 换行 `A` |
| 短问答 | 单行 basic | `Q::A` |

本库 `convertHighlightsToClozes: True`，Cloze 直接用。

## 发音卡（英语必备，独立成卡）

英语每个词/短语要单独做一张发音卡：

- **正面**：正文行写提问，下一行放图片，再下一行写 `?`（视觉联想，AI 联网搜图下载到 `T-附件/images/<word>.jpg`）
- **背面**：`[<word>](发音链接)` + 美式 IPA + `![[T-附件/audio/<word>.mp3]]`
- **卡型**：多行 basic（`?` 分隔）
- **分类**：`#flashcards/英语/<阅读主题>`（如 AI、日常、商务）

⚠️ **图片和正面文字都不能写成 `###` 标题**：`getQuestionContext` 会把 heading 原文塞进面包屑（只剥脚注），卡片上方会显示一行字面量 `![[T-附件/images/xxx.jpg]]`；正文行则不进面包屑。图片放正面文字**下一行**、`?` **之前**——既在正面，又不进面包屑。

**发音链接（youglish 真语料）**：背面出现的**每个英文词/词组**都挂 youglish 链接，链接文字写词本身。

```markdown
[artificial](https://youglish.com/pronounce/artificial/english)
[artificial intelligence](https://youglish.com/pronounce/artificial%20intelligence/english)
```

- 单词：`https://youglish.com/pronounce/<word>/english`
- 词组：空格换成 `%20`（实测有效，如 `artificial%20general%20intelligence`）
- **不用中文谐音**：谐音无法准确还原真实发音（会固化错误口型）。youglish 给真实视频语料，既能核对又能矫正发音
- **不加 `🔊` 图标**：音频嵌入 `![[...mp3]]` 自带播放按钮，图标冗余
- **不加独立 `发音参考：` 行**：链接已贴在词上，独立行冗余
- **Cloze 行例外**：Cloze 两面共享文本，链接挂上去等于正面报答案 → Cloze 行的词保持纯文本，链接只在多行卡背面挂
- **不挂的**：拼写/重音字母片段（如 `-gence`、`-TEL-`）、音频文件名、出处笔记名

**发音生成命令**：
```bash
~/.config/magpie/library/skills/flashcard/scripts/tts-flashcard.sh "<英文短语>" "<文件名>"
# 如: ~/.config/magpie/library/skills/flashcard/scripts/tts-flashcard.sh "artificial" "artificial"
# 输出: T-附件/audio/artificial.mp3（用微软 Christopher en-US-ChristopherNeural）
# 失败降级: say -v Samantha → m4a
```

**搜图**：AI 联网搜一张与词义相关的免费图片（优先 Unsplash），下载到 `T-附件/images/<word>.jpg`，卡片正面用 `![[T-附件/images/<word>.jpg]]`。

**图片必须轻量化**（硬要求，下载后立刻压）：

```bash
# 最长边 1200px，够看清又不占库（2.6MB → ~365KB）
sips -Z 1200 "<下载的图>" --out "T-附件/images/<word>.jpg"
```

- 统一用 `.jpg`（来源是 PNG/WebP 也转存成 jpg，Obsidian 都认）
- 单张 ≤ 500KB；超了先降 `-Z 900` 再降质量
- 目录别堆原图：下载落 `/tmp`，压缩定名后再放进 `T-附件/images/`


## 每张卡必须有的

- **正面**：场景线索（"什么场景下我要想起它"），不是"X 是什么"
  - 英语语境卡：正面写单词 + 原句语境（从原文摘录的短句），激活情景记忆
- **背面**：答案 + ⚠️易错点 + 🧠记忆法/直觉 + 出处链接
- **出处**：wikilink 到来源笔记（如 `[[Transformer注意力机制]]`）或外部来源。出处只挂来源本身，不加词典名（如 OALD）
- **语言类卡**：美式 IPA + 发音链接 + 音频

## 多模态 + 主动输出

- **多模态**：视觉（图片）+ 听觉（音频）+ 动觉（朗读例句、手写抄录、造句说出来）
- **主动输出**：用新词造有个人意义的句子；向朋友复述观点；在日记/邮件中刻意用新词
- 这些不一定要做成卡，但制卡时要想"这个词我能在什么场景说出来"

## 禁止

- 列举题（"说出 3 个…"）→ 反转为单点判断卡
- 长列表/批量对译表
- 还没理解就做卡

## 泄底判定（源码核实 2026-10-14，别一刀切）

**只按一个标准判：这段文字进不进面包屑。**

| 写法 | 去处 | 出现答案词 |
|---|---|---|
| `#` / `##` | **进面包屑**（`文件名 > H1 > H2 > …`） | ❌ 真泄底，必须中性描述 |
| 正面正文行 | **就是正面**（`?` 之前的全是正面），**不进面包屑** | ✅ 是提取线索，该给 |

源码依据：
- 面包屑：`getQuestionContext`（`note-file.ts`）只收 **heading**（`fileCachedData.headings`），本库 `showContextInCards=True` 无条件拼在卡片上方 → H1/H2 写答案词必泄底
- 多行卡：`QuestionTypeMultiLineBasic.expand` → `side1 = slice(0, lineIdx(?))` → 正面正文行是正面的组成部分
- Cloze：`parser.ts` 里 `isClozeNote(currentLine)` 直接扫整行 → 正面正文行里的 `==挖空==` 就是 Cloze 主体

**所以：**

- `# 一、artificial` ❌ → `# 一、AI 主题词汇 · 第一组` ✅（heading 泄底，中性化）
- `## 2.2 点积` ❌ → `## 2.2 相似度度量（产出）` ✅（同上）
- 正面正文行写 `artificial 这个词怎么读？` ✅（在正面，不进面包屑，该给）
- 正面正文行写 `artificial 接名词指什么？（intelligence…）` ✅（只留本词，别带会一起泄底的例句词——例句写背面）

⚠️ **别把正面写成 `###` 标题**：heading 既渲染进卡片正文、又进面包屑 → 同一句话显示两遍，且平白多一处泄底面。正面一律用正文行。

⚠️ **别反过来删正面里的词**：那是**提取线索**，不是泄底。删了词 = 用户不知道在问什么 = 废卡。真正要中性化的只有 `#` 和 `##`。


## 改卡规范

进度存在 `<!--SR:-->` 注释里（NOTES 模式）。改正面会丢进度（匹配靠逐行精确比对，不是 hash）。**丢了无所谓，卡做好比保进度重要。** 只改背面则进度保留。

改前改后跑一次校验：
```bash
grep -c "SR:" 文件.md   # 改前后各一次，一致=进度没丢
```

## 自检清单（写完每张卡过一遍）

- [ ] 正面是场景线索，不是"X 是什么"？
- [ ] 一张卡只问一件事？（没有列举、没有双问）
- [ ] 看到正面能先想再答，还是一眼泄底？（按上面「泄底判定」判，别一刀切删词）
- [ ] 正面用的是**正文行**，不是 `###` 标题？（标题会重复显示 + 进面包屑）
- [ ] `#` / `##` 措辞中性、不含答案词？
- [ ] 背面有易错点/记忆法/出处？
- [ ] 语言卡带了发音（音频 + IPA）？
- [ ] 背面所有英文词/词组都挂了可点击的发音链接？（链接文字=词本身，无 `🔊`、无独立 `发音参考：` 行）
- [ ] 背面挂了出处链接？

任一不过 = 改卡。

## 新增卡片文件

1. 在本目录新建 `<主题>.md`
2. frontmatter 加 `tags:` 和 `source:`
3. 正文首行 `#flashcards`
4. 按格式模板写卡（两层 `#` → `##` + 独立标签行 + 正面正文行）
5. 英语卡跑 `~/.config/magpie/library/skills/flashcard/scripts/tts-flashcard.sh` 生成发音 + 联网搜图
6. 过自检清单
